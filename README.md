# Restaurant Backend

Серверная часть клиент-серверного приложения для сети ресторанов, разработанного как итоговый проект курса Samsung «Android-разработка на Kotlin».

Backend предоставляет REST API для Android-приложения, хранит данные пользователей и ресторанов, обрабатывает бронирования и содержит веб-панель администратора.

## Возможности

### Для Android-приложения

- регистрация и авторизация пользователей;
- авторизация по номеру телефона;
- аутентификация с помощью JWT;
- получение данных профиля пользователя;
- загрузка изображения профиля;
- просмотр ресторанов;
- получение меню и категорий блюд;
- синхронизация избранных блюд;
- получение новостей выбранного ресторана;
- бронирование столиков;
- контроль количества гостей;
- система лояльности.

### Для администратора

- управление ресторанами;
- создание и редактирование категорий;
- создание и редактирование блюд;
- управление столиками;
- публикация новостей;
- привязка данных к конкретному ресторану;
- управление данными через веб-панель.

## Архитектура

Проект разделён на несколько основных слоёв:

- `controller` — обработка HTTP-запросов;
- `service` — бизнес-логика приложения;
- `repository` — взаимодействие с базой данных;
- `entity` — сущности базы данных;
- `dto` — модели входных и выходных данных;
- `config` — конфигурация безопасности и приложения;
- `exception` — обработка ошибок;
- `scheduler` — выполнение запланированных операций.

## Безопасность

Для защиты пользовательских данных применяются:

- Spring Security;
- хеширование паролей;
- JWT-токены;
- разграничение доступа к пользовательским и административным функциям;
- валидация входящих данных.

## Android-приложение

Android-клиент находится в отдельном репозитории: [RestaurantAppProject](https://github.com/Danyak15/RestaurantAppProject)

Клиент разработан на Kotlin с использованием Android XML, MVVM, Retrofit, Room, Hilt и WorkManager.

## Запуск проекта

### Требования

- JDK 24;
- Git;
- доступ к Maven Central;
- PostgreSQL при использовании соответствующей конфигурации.

### Настройка базы данных

Параметры подключения находятся в:

```text
src/main/resources/application.properties
```

Перед запуском укажите адрес базы данных, имя пользователя и пароль согласно выбранной конфигурации.

### Запуск на Windows

```powershell
.\gradlew.bat bootRun
```

### Запуск на macOS или Linux

```bash
./gradlew bootRun
```

По умолчанию сервер запускается по адресу:

```text
http://localhost:8080
```
